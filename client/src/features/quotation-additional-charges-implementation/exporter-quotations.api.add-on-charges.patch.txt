Update the existing ExporterSubmission/ExporterSubmissionItem types without replacing the API module.

On the submission type, add:
  customsChargeRequested?: boolean;
  invoiceValue?: string | number | null;
  invoiceCurrency?: string | null;
  transportChargeRequested?: boolean;
  vatEnabled?: boolean;
  vatPercentage?: string | number;
  customerMessage?: string | null;
  taxAmount?: string | number | null;

On the item type, add:
  itemType?: "SERVICE" | "CUSTOMS_CHARGE" | "TRANSPORT_CHARGE";

Ensure the detail endpoint's response type includes these scalar fields and itemType. The Prisma relation `include: { items: true }` returns them after the migration and `prisma generate`.
